Това е ASP.NET Core MVC приложение за управление на паркинг система и с VIP клиенти.
Според функционалностите това е  система за паркинг управление приложението включва основни функционалности свързани с:

✅ Следене на паркинг пространства и управление на превозни средства
✅ Вписване/изписване на автомобили с изчисляване на такси
✅ Управление на VIP клиенти и техните превозни средства
✅ Система за месечни точки с автоматично нулиране
✅ Валидация на формите както на сървъра, така и в браузъра
✅ Модерна архитектура на уеб приложение използвайки ASP.NET Core MVC

Ето основните компоненти:

Структура на проекта:
Controllers: Контролери за основни функционалности (Parking, Vip, Error)
Models: Модели за данни (Car, Client, ParkingSpace, VipCarRecord, VipPoint, CheckInVm, VipCreateVm)
Data: База данни (ParkoDbContext) с Entity Framework
Services: Услуги (ParkingService) за бизнес логиката
Views: HTML шаблони за потребителския интерфейс
Основни функционалности е паркиране на автомобили:

Регистрация на пристигане с номер, модел и избор на място
Автоматично заделяне на свободно място (от 1 до 100)
Проверка дали автомобилът вече е паркиран
Отписване от паркинга:

Изчисляване на цена според времето на престоя
Тарифи: до 15 мин безплатно, след това 1,20 €/час за VIP клиенти и 1 €/час за обикновени клиенти
VIP система:

Клиенти с VIP статус получават точки за използване
Всяко паркиране от VIP клиент използва 1 точка (ако има такива)
Точките се възстановяват на първия ден на месец (40 точки на месец)
База данни:

Използва SQL Server LocalDB
Миграции са активирани
Има 100 паркинг места (от 1 до 100)
Техническа информация:
.NET 8.0
Entity Framework Core 8.0
SQL Server
MVC архитектура
Бизнес логика:
Автомобилите се паркират в свободни места. За VIP клиенти се използват точки за безплатно паркиране. При излизане се изчислява цена според тарифата.
